# EPAM Lead Prep Pack

Everything for the EPAM QA Automation Team Lead interview, on one page.

### 👉 [Open it here](https://aishwariyaj23.github.io/epam-prep/)

Works on a phone. Progress (checkboxes, flashcard piles, chosen tab) is saved in
whichever browser you open it in.

**12 tabs:** Start · Plan · Java · Programs · Selenium · API · Spot the Bug ·
Framework · Lead Round · Flashcards · Carry Sheet · Day Of

- **Programs** — 26 coding questions with full solutions, edge cases and the follow-up
- **Spot the Bug** — 27 defect-hunting drills
- **Framework** — how to explain a framework in an interview, with diagrams
- **Flashcards** — 82 rapid-recall cards with a revise pile
- **Carry Sheet** — one printable A4 page for the day itself (Ctrl+P)

The runnable framework that the Framework tab walks through lives at
**[epam-prep-framework](https://github.com/Aishwariyaj23/epam-prep-framework)**.
