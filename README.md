# EPAM Lead Prep

Interview preparation for a QA Automation Team Lead role. Two pages, both live
and openable from any machine.

---

## 📘 [The Prep Pack](https://aishwariyaj23.github.io/epam-prep/) — for the candidate

Everything on one page, 12 tabs:
**Start · Plan · Java · Programs · Selenium · API · Spot the Bug · Framework ·
Lead Round · Flashcards · Carry Sheet · Day Of**

- **Programs** — 26 coding questions with full solutions, edge cases and follow-ups
- **Spot the Bug** — 27 defect-hunting drills
- **Framework** — how to explain a framework in an interview, with diagrams
- **Flashcards** — 82 rapid-recall cards with a revise pile
- **Carry Sheet** — one printable A4 page for the day itself (Ctrl+P)

Works on a phone. Checkboxes, flashcard piles and the open tab are saved in
whichever browser you open it in.

---

## 📋 [The Mock Panel Runsheet](https://aishwariyaj23.github.io/epam-prep/runsheet.html) — for the interviewer

**This one is for whoever runs the practice interview, not for the candidate.**
It contains the model answers.

A timed 60-minute mock: 38 questions across five segments, each with what to
listen for and the follow-up to push with. Segment timer and a live scorecard
that flags the weakest area.

---

## 🔧 The runnable framework

The project the Framework tab walks through lives at
**[epam-prep-framework](https://github.com/Aishwariyaj23/epam-prep-framework)** —
Selenium 4, TestNG and REST Assured, with `run.cmd` to launch it.
